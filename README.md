# Verotides.com

Core command interface for Mike Foley's "Mad Lab" operations.

## Components

### 1. Vero Beach Utility Hub
A hyper-local utility dashboard for Vero Beach, FL.
- **Tide Dynamics**: Live tide predictions from Sebastian Inlet.
- **Bite Windows**: Solunar-calculated fishing activity.
- **Beach Sentry**: Real-time conditions and turtle nesting status.
- **Trash Routing**: Address-based pickup schedules.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS (Terminal/CRT Aesthetic)
- **Deployment**: Vercel + GitHub
- **Data**: NOAA Tides/Weather, FWC Red Tide, IRC GIS

## Installation

```bash
npm install
npm run dev
```
